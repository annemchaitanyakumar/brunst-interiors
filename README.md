# Brunst Cinematic Interiors

Luxury interior architecture & design studio showcase featuring cinematic scroll choreography, curated project case studies, and an interactive 3D walkthrough tour.

## Tech Stack

- React 19 + TanStack Start / Router
- Tailwind CSS v4
- Three.js (Interactive 3D architectural tour)
- GSAP, Framer Motion & Lenis

## Development

```sh
npm install
npm run dev
```

## Verification & Build

```sh
npx tsc --noEmit
npm test -- --run
npm run build
```
